# [08] 부동산원 (R-ONE) Open API 명세 및 호출 가이드

본 문서는 한국부동산원(R-ONE)에서 제공하는 부동산통계정보 Open API의 사용 방법과 상세 API 명세에 대해 기술합니다. 전체 통계표 목록과 코드 정보는 [[08-1] 부동산원 통계표 코드 목록](file:///E:/apps/myhome/docs/08-1_RONE_API_LIST.md) 문서에서 확인할 수 있으며, API 연동에 필요한 행정구역 지역코드 정보는 [[08-2] 부동산원 지역코드 마스터 목록](file:///E:/apps/myhome/docs/08-2_RONE_API_REGION_CODE.md) 문서에서 확인할 수 있습니다.

## 1. 개요 및 인증 설정
- **인증키 설정**: 로컬 환경 변수 파일(`.env`)의 `RONE_API_KEY` 키값에 발급받은 인증키를 설정하여 연동합니다.
- **웹서비스 방식**: 부동산통계정보 Open API는 **RESTful 방식의 웹서비스**로 제공됩니다.
- **호출 매커니즘**: HTTP GET 또는 POST 방식의 URI를 통해 서비스되며, 요청 파라미터 값을 URL에 표기(Query Parameter)하여 호출합니다.
- **기본 URL**: `https://www.reb.or.kr/r-one/openapi/`

## 2. API 호출 공통 규칙 (기본인자)
부동산원 Open API 호출 시 공통으로 적용되는 기본 인자 정보입니다. 기본인자를 생략하면 명세표의 기본값으로 결과를 표기합니다.

| 변수명 | 타입 | 변수 설명 | 설명 |
| --- | --- | --- | --- |
| Key | STRING(필수) | 인증키 | 발급받은 인증키를 입력해야 합니다. 만약 인증키가 없거나 누락되면 기본값 `sample`로 처리되어 **10건만 출력**되므로 반드시 `RONE_API_KEY`를 사용해야 합니다. |
| Type | STRING(필수) | 호출 문서(xml, json) | 출력하고자 하는 데이터 타입 형태를 지정합니다. (기본값: `xml`) |
| pIndex | INTEGER(필수) | 페이지 위치 | 출력하고자 하는 페이지 번호입니다. 데이터 수가 많은 경우 페이지 위치를 증가시키면서 여러 번 분할 호출해야 합니다. (기본값: `1`, sample key는 1로 고정) |
| pSize | INTEGER(필수) | 페이지당 요청 숫자 | 한 페이지에 출력될 데이터 건수입니다. (기본값: `100`, sample key는 5로 고정) |

## 5. 실제 API 호출 및 항목 매핑 예시
부동산원 Open API 호출을 설정할 때 대표적으로 사용되는 `(월) 매매가격지수_주택종합` 통계 데이터 조회의 실제 예시입니다.

### 5.1 호출 상세 조건 매핑
- **통계표명**: `(월) 매매가격지수_주택종합` (통계표 ID: `A_2024_00016`)
- **세부 항목명**: `지수` (항목코드 / ITM_ID: `100001`)
- **수집 주기**: `월` (주기코드: `month` 또는 API 주기코드)

### 5.2 RESTful API 호출 URL 예시
```http
GET https://www.reb.or.kr/r-one/openapi/SttsApiTblData?Key=YOUR_RONE_API_KEY&Type=json&pIndex=1&pSize=100&STATBL_ID=A_2024_00016&DTACYCLE_CD=month&ITM_ID=100001
```
- `.env`에 정의된 `RONE_API_KEY`를 `Key` 파라미터에 할당하여 호출합니다.
- `STATBL_ID`에 `A_2024_00016`를 넘겨 주택종합 매매가격지수 통계표를 특정합니다.
- `ITM_ID`에 `100001`을 매핑하여 해당 통계표의 세부 항목인 **지수** 값을 필터링하여 조회합니다.
